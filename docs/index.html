Tennis Value Board

lädt …
–Partien
–Value-Wetten
–Einsatz gesamt (Units)
–Ø Edge der Tipps
–Tipps (gew.–verl.)
–Trefferquote
–ROI (1 U je Tipp)
–Gewinn flach (1 U je Tipp)
–Gewinn mit Unit-Einsatz
–Ø CLV

Jeder Tipp wird beim ersten Erscheinen vor Spielbeginn mit Zeitstempel und Quote gespeichert und danach nicht mehr verändert. Ergebnisse werden automatisch nachgetragen (Folgerunde im Turnier bzw. Abrechnung von OddsPapi), Schlussquote = letzte Quote des Buchmachers vor Spielbeginn. CLV = Tippquote ÷ Schlussquote − 1: Positiv heißt, der Markt hat sich nach dem Tipp in deine Richtung bewegt.

–Wetten (gew.–verl.)
–Einsatz abgerechnet
–Gewinn / Verlust
–ROI
–offen (Einsatz)
–Ø Quote
Wette manuell eintragen (für Partien, die nicht auf der Seite stehen)
Abgleich zwischen Geräten nicht eingerichtet – Wetten liegen nur in diesem Browser

Deine Wetten werden in einem geheimen GitHub-Gist gespeichert (nicht öffentlich gelistet, nur mit deinem Schlüssel beschreibbar) und so zwischen Handy und PC abgeglichen. Schlüssel anlegen: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → nur Haken bei gist. Der Schlüssel bleibt in diesem Browser gespeichert und wird nirgends veröffentlicht. Auf dem zweiten Gerät denselben Schlüssel eintragen – der Gist wird automatisch gefunden.
